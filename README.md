# wx-2048-quest

## 项目简介
wx-2048-quest 是一个关卡制 2048 微信小程序项目，本轮 (R1) 仅交付最小可运行骨架：原生小程序页面占位、云开发目录预留，以及一个用于浏览器验收的纯前端 HTML 页面。

## 技术栈
- 微信小程序原生框架（含增强编译、ES6 支持）
- 微信云开发（R5+ 才会启用）
- `/core/` 目录用于编写与平台无关的 2048 核心逻辑，未来将被小程序与 `/web-sim/` 共用

## 本地开发前置
1. 安装并登录微信开发者工具。
2. 在开发者工具中启用云开发（当前轮次未使用，R5+ 再接入）。

## R1 验收方式
1. 浏览器打开 `web-sim/index.html`，应显示 “wx-2048-quest ready（R1）”。
2. 使用微信开发者工具导入 `wx-2048-quest/` 仓库根目录：
   - AppID 暂用 `touristappid`，后续替换为真实小程序 AppID；
   - 运行后模拟器首页显示“首页就绪（R1）”，可跳转到“游戏/结果”占位页；
   - 预览二维码仅用于本地调试，R5+ 才会启用云能力。

## 合规与备案（个人主体）
- 上线前需要在微信公众平台完成小程序 APP 备案（个人可办理）。
- 项目不涉及 `<web-view>` 外链域名，无支付/内购，仅提供玩法体验。
- 若后续版本直连外部服务，需要在“开发管理 → 开发设置 → 服务器域名（合法域名）”配置 HTTPS 域名。

## 下一步计划
- **R2**：实现 2048 核心逻辑模块（纯 JS，可被 `/web-sim` 复用）。
- **R3**：完成关卡配置模型（示例：第一关 gridSize=2 且仅生成 2 或 1）。
- **R4**：小程序渲染与手势交互。 **R5**：云开发与登录绑定。

## 进度 R2

- 小程序端仍为占位，R3 起接入关卡与渲染

### 引擎用法简例
```js
import { createGame, DIRECTIONS } from "./core/game.js";
const g = createGame({ gridSize: 2, spawnValues: [2], target: 16, seed: "demo" });
g.move(DIRECTIONS.LEFT);
console.log(g.getSnapshot());
```
